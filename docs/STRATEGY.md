## The story to explain

Software pays a device for a fresh physical check. The device signs the request and answer.
The buyer verifies the source, request, and age. [Current explanation and limits](competition/STORY.md).

## The wedge to test first

Paid remote inspection jobs for remote-operations software companies, where an existing API fails and a manual check costs money.
This is a buyer hypothesis. No customer or willingness to pay is established.

## Validate one relationship

Find one authorized operator and one recurring decision. Compare FieldProof with the current API or manual check.
Then test another operator and measure integration reuse. [Falsifiable pilot](competition/PILOT.md).

## Product risks and decisions

Current gaps include physical trust, production authorization, buyer value, pricing, provider margins, and live peaq integration.
A signature authenticates a claim. It does not establish truthful sensing.
[Current status](FOCUS.md) · [Integration facts](PEAQ_INTEGRATION.md).
